## ✨ Features

### 🏠 Homepage
- Modern hero slider with featured popular movies
- Movie tabs showing "Now Playing" and "Popular Movies"
- Responsive design with gradient backgrounds
- Dynamic movie posters and ratings

### 🔍 Search & Discovery
- Advanced search with real-time filtering
- Search by title, director, or actor
- Filter by genre and release year
- 30 pre-loaded blockbuster movies

### 🎭 Movie Collection
- Complete movie library with 30+ titles
- Genre-based categorization (Action, Comedy, Drama, Sci-Fi, etc.)
- Release years from 2021-2022
- Movie details including ratings, duration, cast, and descriptions

### 👤 User System
- Local storage-based authentication
- User registration and login
- Profile management
- Favorites system (planned)
- Booking history (planned)

### 🎨 Modern Design
- Dark theme with purple/pink gradients
- Glass-morphism effects with backdrop blur
- Responsive layout for all devices
- Smooth animations and hover effects
- Professional movie card designs

## 🛠️ Technical Features

### Static Website
- No server dependencies
- Works entirely client-side
- Fast loading with local data
- No database required

### Data Management
- JSON-based movie database
- Local storage for user data
- Service layer for data operations
- Simulated API delays for realism

### Modern UI/UX
- Tailwind CSS + DaisyUI
- React with Vite
- Responsive design
- Professional animations

## 🚀 Getting Started
